# 台指選擇權看台

在自己電腦上跑的台指選擇權（TXO）工具：即時報價看台，加上一個教新手**預測區間、而不是猜單點**的教學頁。另附權證看台。

> **免責聲明**：個人學習用工具，不構成任何投資建議，也不提供買賣推介。頁面上的機率與區間都是把市場報價做數學換算、或對歷史資料回測的結果，不保證未來。行情來自臺灣期貨交易所公開資訊與 FinMind，請遵守各來源的使用條款；本專案不附帶、也不散布任何原始行情資料。

## 快速開始

1. 裝好 Python 3（只用標準函式庫，不需要 pip 安裝任何東西）。
2. Windows：雙擊 `run_local.bat` 開看台、`run_learn.bat` 開教學頁。Mac／Linux：`python3 serve.py`；教學頁加 `--path /learn`。
3. 瀏覽器會打開 http://127.0.0.1:8770/ 。報價直接向期交所抓，需要連網。

你的紀錄只存在自己的電腦：模擬單在 `paper/`、練習場的預測在 `forecasts/`，第一次存檔時自動建立，不會被上傳。

## 教學頁（/learn）

| 課 | 內容 |
|---|---|
| 1. 市場已經畫好區間 | 用即時報價算出今天 50%／68%／90% 的結算區間、鐘形曲線，以及歷史上這種區間實際命中多少 |
| 2. 四個基本動作 | 買／賣 × 買權／賣權、為什麼不裸賣；用即時報價動手拼 8 種組合，看成本、最多賺賠、打平點、到期賺錢的機率 |
| 3. 區間預測練習場 | 不用下單：說出「結算在 X～Y、把握幾成、為什麼」，結算後用區間分數同時替你和市場打分，附成績卡與校準圖 |
| 4. 常見誤會 | 買賣權牆、max pain、盤整收租、蝶式抱到結算、猜 ±100 點——各附歷史實測數字 |

## 看台（/）

- **報價鏈**：期交所即時報價，日盤／夜盤自動切換；標的價用同一批選擇權的買賣權平價算，不用不同到期的期貨。
- **策略快建與變化表**：依看法分組的常見結構，用 delta 選履約價；同一招列出其他選法比較。
- **依看法排策略**：填「結算在 X～Y、把握幾成」，用可成交價算各結構在你看法下的期望值並排序；同時告訴你市場給這段區間多少機率。
- **部位**：權利金拆帳、期交所公式保證金、拆成可直接送出的複式單清單；**預設禁止裸賣**。
- **到期損益圖**：游標移上去顯示該點的指數與損益。
- **停損／掛單檢查**：填一個價位，告訴你到期前被碰到的機會（停損被觸發）、到期真的收在那一邊的機會，以及兩者的差＝被洗掉的機會。
- **買賣權牆**：前一交易日各履約價的未平倉量與增減（附長條圖），標明不能當預測用。
- **模擬單・前測**：用可成交價記錄進場，自動估值、到期抓期交所最後結算價結算；顯示目前吃到最大獲利的幾成。
- **決策引導**：五步工作表，把看法變成候選價差並檢查風險（預設收起）。
