# 權證看台

獨立於原台指選擇權看台的本機工具，位於 `warrants/`，預設使用 **8771** 埠。

## 啟動

雙擊專案根目錄的 `run_warrants.bat`。使用 Python 3 標準函式庫，不需要安裝額外套件。

```powershell
python warrants/serve.py
```

8771 若已經是權證看台在跑，會直接開瀏覽器過去，不會重開一個；若被別的程式占用，會自動往後換埠（8772、8773……），看終端機顯示的網址。

瀏覽器開啟 http://127.0.0.1:8771/ 。終端機 Ctrl+C 關閉服務。無法連線時可選「試用教學範例」，所有範例明確標示為虛構。

## 使用流程

1. 輸入股票代號／名稱或權證代號，依方向、市場、剩餘天數篩選。搜尋按到期日排序、每頁 12 檔。
2. 點選權證，確認最新履約價、每單位履約比例、最後交易日、到期日及報價時間。進場價以賣價預填；沒有賣價時自行輸入。
3. 填張數加入模擬，1 張＝1,000 單位。組合限制同標的、同到期日，均為買進認購／認售。
4. 調整目標價、經過幾天及情境 IV。金線是股票／ETF 標的參考價；黑實線是到期損益；藍虛線是未到期的理論損益；綠虛線是目標價。輸入會立即更新。
5. 同頁比較依「相同情境 IV、目標價、天數」計每檔一張的理論報酬率。它沒有預測未來，也不代表發行商保證依該模型報價。最後交易日後只可看理論價值，不能假設可場內平倉。
6. 保存模擬單，之後手動記錄平倉／到期結果。平倉用使用者核對的每單位賣出價；到期用使用者填寫的官方標的結算價。**不會自動抓最後結算價或自動結算，也不會送出交易委託。**

模擬部位與追蹤單保存於瀏覽器 `localStorage`，只在同一瀏覽器、同一 host 與 port 可見。清除瀏覽器資料會遺失，請用「匯出備份」下載 JSON。「還原備份」合併追蹤紀錄、略過同 ID；目前組合會被還原的組合取代。移除／清空可在本次頁面工作期間按「復原」。

## 支援範圍與計算口徑

- 一般型、以台灣股票／ETF 為標的的認購／認售。牛熊證、展延型、指數與海外標的不使用此模型。
- 歐式 Black–Scholes，股息用可調連續殖利率近似。美式權證只作歐式近似、未計提前履約價值。特殊配息、條款調整與發行商波動率變化不保證被模型捕捉。
- 每單位到期價值：認購 `max(S-K,0)×比例`；認售 `max(K-S,0)×比例`。
- IV 以所選權證中價反推；缺雙邊時可用最後成交價作反推參考，無法反推時保留情境 IV。這不等於可成交價，進場仍看賣價、估計賣出看買價。
- 同組合的情境採共同 IV，可手動調整；讀取報價時，如未手動改過，對回所選權證。不同權證可能有不同發行商報價政策。
- 買賣雙邊各計手續費（預設 0.1425%、最低 20 元／筆），賣出及現金履約稅預設 0.1%。到期線以相同手續費參數近似現金履約費，應依券商調整；未計滑價與整元進位。
- 到期歸零損失為買進成本加進場費；極低價平倉的退出最低費用可能讓虧損超過此數，所以不稱為含所有交易費用的絕對最大虧損。
- 個別部位成本、代號及到期日固定，選取另一檔不會偷偷換掉原部位。官方報價不會改寫進場成本。

## 資料來源

- [TWSE 上市權證收盤資訊](https://www.twse.com.tw/zh/products/securities/warrant/infomation/stock.html)：`/rwd/zh/stock/warrantStock?response=json`。
- [TPEx OpenAPI](https://www.tpex.org.tw/openapi/)：`tpex_warrant_issue`、`tpex_warrant_daily_quts`、`mopsfin_t187ap37_O`。最新比例直接採每單位欄位，不把每仟單位數值誤當比例。
- [TWSE 網站行情](https://mis.twse.com.tw/stock/index.jsp)：個別權證與標的行情（網站來源，非券商低延遲串流）。每 15 秒輪詢，後端 10 秒快取；逐檔保留日期時間、買價、賣價。缺值不補成可成交價格。
- 基本資料快取一小時，存在 `runtime/`。來源失敗可使用先前快取並標示錯誤；頁面保留日期供核對。收盤／過期行情不顯示成當下即時。
- [證交所權證教育與費稅](https://www.twse.com.tw/zh/products/securities/warrant/educate/qa.html)。各商品實際結算方式與最後交易日仍以發行條款為準。

## 測試

```powershell
node --test warrants/test_model.cjs
python -m unittest discover -s warrants -p "test_*.py"
node --check warrants/app.js
```

Node 僅用於開發測試，使用看台只需要 Python 與瀏覽器。測試涵蓋比例、費稅、認購／認售、IV 反推、到期邊界、官方資料解析與缺報價；頁面再以真實瀏覽器檢查。

## 檔案

- `data.py`：官方來源、快取、正規化、搜尋。
- `serve.py`：本機唯讀 API 與靜態檔案白名單，僅綁定 127.0.0.1。
- `model.js`：純計算函式。
- `app.js`、`index.html`、`style.css`：介面、狀態、損益圖、追蹤與備份。

原本 `serve.py`、`txo_desk.html`、`paper/` 與啟動檔均未修改。

## 損益圖的游標讀數

滑鼠移到圖上會出現十字線與讀數框：標的價（到 0.1 元）、距目前標的價幾元、該價位的到期損益與情境理論損益（賺紅賠綠）。兩個值都是當場用定價函式算的，不是查曲線上的取樣點，精度再細也不多花效能。手指拖曳同樣有效，移開就消失；每 15 秒更新報價重畫時，十字線會留在原位。

橫軸改用等距的整數刻度（`niceTicks`），不再是把上下界五等分後的零碎數字。
