# 權證看台

延續本機 Python + 原生 JavaScript 架構，獨立使用 8771 埠，不修改 TXO 看台。

主要流程：搜尋標的／權證 → 比較同標的商品 → 加入模擬部位 → 調整目標價、天數及 IV → 追蹤與手動平倉。

支援台灣股票／ETF 一般型認購、認售；只建立買進部位。海外、指數、牛熊證、展延型不套入一般股票模型。歐式 Black–Scholes 為情境近似，美式須明示忽略提前履約價值；現金股息以殖利率近似，條款調整須以官方最新數值為準。

資料來源：TWSE warrantStock、TPEx tpex_warrant_issue / daily_quts / mopsfin_t187ap37_O，網站 MIS 個別行情。個別商品保留報價日期、時間、買價、賣價；基本資料與行情分開標示。失敗保留舊資料且明示，範例需明確選擇。

計算：每單位價值乘履約比例，1 張 = 1,000 單位；費用可調，買賣分別計手續費、賣出／現金履約試算稅。現價估值、情境理論與到期假設分開。部位固定代號、標的、到期、進場成本；同一張圖只合併同標的同到期部位。

驗收：官方樣本解析、call/put/比例/費稅/IV/到期邊界測試；在真實瀏覽器完成範例搜尋、加入、情境調整、保存與平倉；手機排版可操作。保存於本機瀏覽器，提供 JSON 匯出與還原；無自動下單。
